# Iris Data Visualization

## 📌 Objective
This project focuses on visualizing and analyzing the Iris dataset using Python libraries like Pandas, Matplotlib, and Seaborn.

## Dataset
The Iris dataset contains measurements of iris flowers:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Tools & Libraries Used
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created
1. Bar Chart
2. Histogram
3. Scatter Plot
4. Pair Plot
5. Correlation Heatmap

## Key Insights
1. The dataset contains three iris flower species: Setosa, Versicolor, and Virginica, with equal distribution among them.
2. Setosa species is clearly distinguishable from the other two species because it has smaller petal length and petal width values.
3. Virginica flowers generally have the largest petal dimensions, while Versicolor lies between Setosa and Virginica.
4. The scatter plot shows a strong positive relationship between sepal length and petal length.
5. From the pair plot, petal-related features provide better separation between species compared to sepal-related features.
6. The correlation heatmap shows that petal length and petal width are highly positively correlated.
7. Sepal width has a weaker correlation with the other features.
8. Data visualization makes it easier to understand patterns, relationships, and species classification in the Iris dataset.

## Conclusion
This project demonstrates how data visualization helps identify relationships, trends, and classifications within datasets.
